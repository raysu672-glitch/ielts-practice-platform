# 阅读同义替换学习

本目录是阅读同义替换学习模块，作为主站中的 iframe 学习页使用。

## 文件说明

| 文件 | 作用 |
|---|---|
| `index.html` | 学习页主体、词组数据、练习交互 |
| `logo.png` | 模块品牌图 |

## 接入方式

| 项目 | 配置 |
|---|---|
| 访问路径 | `/tongyitihuan/` |
| 主站模式 | iframe |
| `module_type` | `reading_synonym` |
| 学习记录 | 主站根据 iframe 打开时长写入 `study_sessions` |

## 维护注意

| 项目 | 要求 |
|---|---|
| 路径稳定 | 不要修改目录名，否则主站入口会失效 |
| 数据修改 | 词组内容集中在 `index.html` 内，改动后检查学习流程 |
| 验证方式 | 从主站学生端进入“阅读同义替换学习”，退出后检查学习时长 |
