# 长难句学习

本目录是长难句结构学习模块，提供句子拆解、核心成分识别和练习内容。

## 文件说明

| 文件 | 作用 |
|---|---|
| `index.html` | 学习页主体、句子数据、分析展示和练习交互 |

## 接入方式

| 项目 | 配置 |
|---|---|
| 访问路径 | `/changnanju/` |
| 主站模式 | iframe |
| `module_type` | `sentence` |
| 学习记录 | 主站根据 iframe 打开时长写入 `study_sessions` |

## 维护注意

| 项目 | 要求 |
|---|---|
| 数据维护 | 句子和答案数据位于 `index.html` 内 |
| 内容修改 | 修改中文解析后要检查页面渲染和答案判定 |
| 验证方式 | 从主站进入学习页，完成学习后返回主页检查学习时长 |
