# 答案句听写学习

本目录是答案句听写学习模块，包含答案句音频资源和同义替换练习。

## 文件说明

| 文件或目录 | 作用 |
|---|---|
| `index.html` | 学习页主体、音频播放、练习流程和结果页 |
| `A听力答案句/` | 本地答案句音频文件；本地/服务器本地维护，不提交 GitHub |

## 接入方式

| 项目 | 配置 |
|---|---|
| 访问路径 | `/daanjutingxie/` |
| 主站模式 | iframe |
| `module_type` | `listening_synonym` |
| 学习记录 | 主站根据 iframe 打开时长写入 `study_sessions` |

## 维护注意

| 项目 | 要求 |
|---|---|
| 音频资源 | 新增或改名音频后，确认 `index.html` 中路径候选仍能命中 |
| 迁移部署 | 默认部署不上传音频；服务器需要原始音频时，单独同步 `A听力答案句/`，否则会回退到 TTS |
| 验证方式 | 从主站进入模块，随机播放多条音频，确认无 404 |
