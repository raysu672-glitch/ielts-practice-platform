# 听力 P4 跟读

本目录是听力 Part 4 **跟读倍速训练（学习）**模块，包含音频、字幕/脚本和播放控制。

对应测试模块见 `sources/P4genduceshi/`（跟读录音打分）。

## 文件说明

| 文件 | 作用 |
|---|---|
| `index.html` | 模块入口 |
| `script.js` | 跟读控制、倍速、交互逻辑 |
| `styles.css` | 页面样式 |
| `C4T1S4.mp3` | 跟读音频；本地/服务器本地维护，不提交 GitHub |
| `完整代码.md` | 历史完整代码记录 |

## 接入方式

| 项目 | 配置 |
|---|---|
| 访问路径 | `/P4gendu/` |
| 主站模式 | iframe |
| `module_type` | `listening_p4_speed` |
| 学习记录 | 主站根据 iframe 打开时长写入 `study_sessions` |

## 维护注意

| 项目 | 要求 |
|---|---|
| 音频资源 | 替换音频后同步检查 `script.js` 中的引用；默认部署不上传音频 |
| 倍速训练 | 修改倍速规则后检查桌面和移动端播放控制 |
| 验证方式 | 从主站进入模块，确认音频可播放、倍速可切换 |
| 对应测试 | 测试页在 `../P4genduceshi/`，共享 `module_type=listening_p4_speed` |
