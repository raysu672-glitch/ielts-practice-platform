# 听力跟读

本目录是听力 **P1 / P4 影子跟读**模块。练习走本目录目录页；测试走 `P4genduceshi/`，识别率按主站达标标准计入测试进度。

打开后先选 P1 跟读或 P4 跟读，各 12 篇课文。测试入口只出现 P4 讲座。

## 文件说明

| 文件 | 作用 |
|---|---|
| `index.html` | 模块入口：目录 + 跟读练习页 |
| `lessons-data.js` | 24 篇课文（P1 / P4 各 12） |
| `script.js` | 跟读控制、倍速、录音 |
| `styles.css` | 页面样式 |
| `audio/*.mp3` | 跟读音频；本地/服务器本地维护，不提交 GitHub |

## 接入方式

| 项目 | 配置 |
|---|---|
| 访问路径 | `/P4gendu/` |
| 主站模式 | iframe |
| `module_type` | `listening_p4_speed` |
| 显示名称 | 听力跟读 |
| 学习记录 | 主站根据 iframe 打开时长写入 `study_sessions` |
| 单课链接 | `index.html?lessonId=C4T1S4&part=p4` |

## 维护注意

| 项目 | 要求 |
|---|---|
| 音频资源 | 放到 `audio/`，文件名与课文代码一致（如 `C4T1S1.mp3`）；默认部署不上传音频 |
| 倍速训练 | 修改倍速规则后检查桌面和移动端播放控制 |
| 验证方式 | 从主站进入模块，确认 P1/P4 目录可开、单课音频可播放、倍速可切换 |
| 主站入口 | 学习：本目录；测试：`P4genduceshi/`，达标线读教师「达标标准」 |
