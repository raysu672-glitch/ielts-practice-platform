### 3.1 「计划进度(简)」缩写规则

**仅计划轨**（任务清单内的 `study` 完成数 / 计划 `study` 总数）。**不**显示测试轨 % / 分。

| 任务 `module_type` | 缩写 | 示例 | `parent_module` |
|--------------------|------|------|-----------------|
| `reading_synonym` | 阅 | 阅5/8 | `reading_synonym` |
| `dictation` | 听 | 听11/12 | `dictation` |
| `listening_basic` | 听基 | 听基3/10 | `listening_basic` |
| `listening_synonym` | 听替 | 听替2/8 | `listening_synonym` |
| `sentence` | 长难 | 长难4/12 | `sentence` |
| `writing_phrase` | 词伙 | 词伙6/14 | `writing_phrase` |
| `writing_translate` | 翻译 | 翻译3/23 | `writing_translate` |
| `listening_p4_speed` | P4 | P40/1 | `listening_p4_speed` |
| `speaking_*`（四子块合计） | 口 | 口12/60 | `speaking` |

- 口语：**口 X/Y** = 四子块计划 **学** 条完成合计 / 计划 **学** 条总数合计（**不是** 口语分数）；线框示例统一用 **口12/60** 量级，勿写 口12/24 除非该生清单仅含部分子块  
- 按 **最近有今日任务或最近更新** 的模块优先显示 2 个  
- Hover 浮层：已纳入计划的模块列「学习 X/Y · 过关 A/B」；**不**在浮层里混测试 %

### 3.2 「昨日任务」完成率计算

```text
完成率 = 昨日 state 为 done_study 或 done_pass 的条数 ÷ 昨日总条数
```

| `state` | 计入完成率分子 |
|---------|----------------|
| `done_study` | ✓ |
| `done_pass` | ✓ |
| `done_fail`（测交卷未过关） | **✗** |
| `todo` / `in_progress` | ✗ |

- `done_fail` **不算**完成（产品 P0-1 / D20）
- `in_progress` 不算完成
- 分母含昨日全部条数（含未过关的测）
- 红黄灯直接复用这个 `done/total`（见 §4），看板不会出现「灯和数字打架」

### 3.3 「昨日学习时长」

```text
已练 = 昨日 study_sessions（session_kind=study）秒数合计 ÷ 60，四舍五入
累计 = 该生全部 study_sessions 秒数合计 ÷ 60
```

- 测试时长 **不计入**（与现有主站学习时长口径一致）
- 不再显示「预算」分母（2026-09-19 起装箱只按单元配额，分钟数不约束任何东西）

## 4. 行状态灯（🔴🟡🟢⚪）

**只看昨天那批任务的完成情况**（2026-09-20 决议）。与看板「昨日任务 N/M」一列完全一致：
老师看到 `0/3` 就是 🔴，看到 `2/3` 就是 🟡，不用再对两套口径。
**阶段测和普通任务一样计**：昨天派了阶段测没考、或考了没过（`test_passed` 仍为 0），
都算「没做」，会和普通任务一起决定灯色。

| 状态 | 条件 | 行背景 |
|------|------|--------|
| ⚪ **无有效计划** | 无 pending 条目（未排 或 全部 paused，D28），或计划已暂停/将暂停 | 无着色 |
| 🔴 **需立即关注** | 昨天有任务，且 **一条都没做**（`yesterday_done = 0 且 yesterday_total ≥ 1`） | `#fff5f5` 浅红 |
| 🟡 **建议跟进** | 昨天有任务，**做了一部分没做完**（`0 < yesterday_done < yesterday_total`） | `#fffbeb` 浅黄 |
| 🟢 **正常** | 昨天任务全做完，或昨天没排任务（含「昨天只排了阶段测」——测不算任务量） | 无着色 |

**为什么用「昨天」**：今天的任务还在进行中，上午没做完是正常现象；昨天已经结束，
做没做完是一锤定音的事实——判红不随时间漂移，老师也不必等到下午才看到红灯。

**无有效计划**（未排或全部暂停）与 **需关注** 同时存在时：以 **⚪** 为准，不标红——助教应先排清单或取消暂停。

筛选 Chip **无计划**：含 `none` 与 `all_paused`（或拆两个 Chip；首版合并即可）。

## 5. 标红 / 标黄规则

已合并进 §4，只剩两条：**昨天一条没做 = 🔴**，**昨天没做完 = 🟡**。

以下旧规则**全部取消**（对应的后端常量与判定函数已删除，勿再加回）：

- 红：R1 今日几乎未动（20:00 完成率 &lt;50%）、R2 今日零完成（16:00 完成率 =0%）、
  R3 积压严重（16:00 积压 ≥3）、R4 换题未重学、R5 测多次未过、
  R6 长期失联（连续 7 天 0%）、R7 时长严重不足（&lt; 预算×25%）
- 黄：Y1 今日过半未完成、Y2 有积压（1–2 条）、Y3 今日测挂一次、
  Y4 时长偏低（&lt; 预算×50%）、Y5 计划待生效

积压、换题、测挂仍然**照常展示**（各自成列或行尾标签），只是**不再单独决定状态灯**。
学习任务的完成与否通过「昨天任务 N/M」这一条通道影响灯色；**阶段测不算任务量，
连这条通道也不进**（2026-09-20 第四次修订）。

**例外（唯一的行尾标记）**：**不限重测次数**之后，不存在「考不动了」。剩下的信号是
**累计已考 ≥ `STAGE_TEST_ATTENTION_FAILS`（=3）次仍未过**——这类阶段测会在
「待通过阶段测」列显示红字 **`N 项 多次未过`**。它是**提示助教介入**的独立标记
（看看是内容太难还是达标线偏高），**不参与灯色计算**（灯只看昨天）。

## 6. 筛选 Chip 行为

| Chip | 筛选逻辑 |
|------|----------|
| **全部学生** | 默认；仅 `status=active` 学生 |
| **昨日未完成** | 昨天有任务且 完成率 &lt;100% |
| **今日未完成** | 今日任务存在且 完成率 &lt;100% |
| **有积压** | 积压 ≥1（**昨天**没做完的条数） |
| **有阶段测待通过** | 待通过阶段测 ≥1 |
| **需关注** | 行状态 = 🔴 |
| **无计划** | 行状态 = ⚪ |

- 多 Chip：**AND** 关系  
- 与搜索框：**AND**（学号/姓名模糊匹配）

### 7.1 默认排序

1. 状态优先级：🔴 → 🟡 → ⚪ → 🟢  
2. 同状态：积压降序 → 昨日完成率升序 → 学号升序  

用户可点击列头排序：**昨日任务完成率**、**积压**、**姓名**。

## 13. 双轨进度与进度表（线框补充）

与 [`task-system-overview.md`](task-system-overview.md) §8 一致：**计划轨**（任务 X/Y）与 **测试轨**（进度表 %/分/个）**不合并**；通过 `parent_module` 关联。

```text
┌─ 模块进度 ─────────────────────────────────────────────────────────────┐
│ 模块           │ 计划（任务）      │ 测试（进度表 · 只读）              │
├────────────────┼───────────────────┼──────────────────────────────────┤
│ 阅读同义替换   │ 学 5/8 过关 1/3   │ 78% / 目标 80%                   │
│ 听力1000词     │ 学 11/12 过关 5/6 │ 85% / 目标 80%  ✓                │
│ 口语 · 复合句  │ 学 3/17           │ —                                │
│ 口语 · P1      │ 学 8/24           │ —                                │
│ 口语（汇总）   │ —                 │ 6.0 / 目标 6.5                   │
└────────────────┴───────────────────┴──────────────────────────────────┘
```

- 左列 **计划**：仅该生清单内有的 `parent_module` / 口语子块  
- 右列 **测试**：来自现有 `test_records` + `MODULES`；口语汇总行只显示 **分**

### 13.6 学生 · 任务模式模块页（内容层线框）

与 [`task-system-overview.md`](task-system-overview.md) §7.5、[`task-system-spec.md`](task-system-spec.md) §10.1 一致。助教端不直接展示此页，但验收学生任务时需对照。

**通用结构**

```text
┌────────────────────────────────────────────────────────────┐
│ ← 返回今日任务                                              │
│ 今日任务 · {模块名} · {单元标题}                            │
│ 本单元：{scope_done}/{scope_total} {组|题|句}               │
├────────────────────────────────────────────────────────────┤
│  （仅 content_ref 范围；无全模块目录）                      │
└────────────────────────────────────────────────────────────┘
```

**与 ① 今日任务列表的关系**

| 位置 | 显示 | 禁止 |
|------|------|------|
| ① 列表组头 | 计划学习 **5/8** | 不出现本单元 3/10 |
| ① 单条条目 | 「学 · 单元 6」 | 不出现 78% |
| 模块页（任务模式） | **本单元 3/10 组** | 不出现 5/8、不出现 225 小组总量 |
| ③ 测试与能力 | 测试 **78%** | 不出现 3/10、5/8 |

**听力同义（必改 UI）**

```text
自由练首页：12 组 × 每组 10 题          ← 任务模式下不可出现

任务模式：
  今日任务 · 听力同义 · 单元 2（第 1 组 · 题 6–10）
  本单元：2/5 题
  [逐题练习，共 5 题]
```

**口语 P1**

```text
自由练：已完成 80 / 235 题             ← 任务模式下不可出现

任务模式：
  今日任务 · 口语 P1 · 单元 8
  本单元：7/10 题
```
