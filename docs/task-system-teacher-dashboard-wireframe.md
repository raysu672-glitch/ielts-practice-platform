| **操作** | 64px | — | 链接「计划」 | — |

### 3.1 「计划进度(简)」缩写规则

**仅计划轨**（任务清单内的 `study` 完成数 / 计划 `study` 总数）。**不**显示测试轨 % / 分。

| 任务 `module_type` | 缩写 | 示例 | `parent_module` |
|--------------------|------|------|-----------------|
| `reading_synonym` | 阅 | 阅5/8 | `reading_synonym` |
| `dictation` | 听 | 听11/12 | `dictation` |
| `listening_basic` | 听基 | 听基3/10 | `listening_basic` |
| `listening_synonym` | 听替 | 听替2/8 | `listening_synonym` |
| `sentence` | 长难 | 长难4/12 | `sentence` |
| `writing_phrase` | 词伙 | 词伙6/14 | `writing_phrase` |
| `writing_translate` | 翻译 | 翻译3/23 | `writing_translate` |
| `listening_p4_speed` | P4 | P40/1 | `listening_p4_speed` |
| `speaking_*`（四子块合计） | 口 | 口12/60 | `speaking` |

- 口语：**口 X/Y** = 四子块计划 **学** 条完成合计 / 计划 **学** 条总数合计（**不是** 口语分数）；线框示例统一用 **口12/60** 量级，勿写 口12/24 除非该生清单仅含部分子块  
- 按 **最近有今日任务或最近更新** 的模块优先显示 2 个  
- Hover 浮层：已纳入计划的模块列「学习 X/Y · 过关 A/B」；**不**在浮层里混测试 %

### 3.2 「今日任务」完成率计算

```text
完成率 = 今日 state 为 done_study 或 done_pass 的条数 ÷ 今日总条数
```

| `state` | 计入完成率分子 | 测挂列 |
|---------|----------------|--------|
| `done_study` | ✓ | — |
| `done_pass` | ✓ | — |
| `done_fail`（测交卷未过关） | **✗** | ✓ |
| `todo` / `in_progress` | ✗ | — |

- `done_fail` **不算**今日完成（产品 P0-1 / D20）  
- `in_progress` 不算完成  
- 分母含全部今日条数（含未过关的测）
### 3.3 「今日时长」

```text
已练 = 当日 study_sessions（session_kind=study）秒数合计 ÷ 60，四舍五入
预算 = 当日生效的 weekday_minutes 或 weekend_minutes
```

- 测试时长 **不计入**（与现有主站学习时长口径一致）  
- 无今日任务时仍显示已练/预算（学生可能自由练）

## 4. 行状态灯（🔴🟡🟢⚪）

**优先级从高到低判断，命中即停**（一条规则可对应多列标红）。

| 优先级 | 状态 | 条件（满足任一） | 行背景 |
|--------|------|------------------|--------|
| P0 | ⚪ **无有效计划** | 无 pending 条目：未排 **或** 全部 paused（D28） | 无着色 |
| P1 | 🔴 **需立即关注** | 见 §5 红色规则 | `#fff5f5` 浅红 |
| P2 | 🟡 **建议跟进** | 见 §6 黄色规则（且未命中 P1） | `#fffbeb` 浅黄 |
| P3 | 🟢 **正常** | 有今日任务且未命中 P1/P2 | 无着色 |
| — | 🟢 **今日已完成** | 今日任务 100% 且无积压、无换题、无测挂 | 可选浅绿 `#f0fdf4` |

**无有效计划**（未排或全部暂停）与 **需关注** 同时存在时：以 **⚪** 为准，不标红——助教应先排清单或取消暂停。

筛选 Chip **无计划**：含 `none` 与 `all_paused`（或拆两个 Chip；首版合并即可）。

## 5. 标红规则（🔴 需立即关注）

**单元格标红**：该列数字/文案用 `--danger` 色 + 可选加粗。  
**整行标红**：命中下列 **任一** 条。

| ID | 规则 | 列 | 条件 | 助教建议动作 |
|----|------|-----|------|----------------|
| R1 | 今日几乎未动 | 今日任务 | 当前时刻 ≥ **20:00** 且 完成率 **&lt;50%** 且 今日总条数 ≥1 | 联系学生或明日优先释放更少 |
| R2 | 今日零完成 | 今日任务 | 当前时刻 ≥ **16:00** 且 完成率 **=0%** 且 今日总条数 ≥2 | 同上 |
| R3 | 积压严重 | 积压 | 积压条数 **≥3** | 减清单或提周末时长；清队首卡点 |
| R4 | 换题未重学 | 换题 | 换题重学条数 **≥1** 且 当日仍未完成 | 确认学生看到今日置顶任务 |
| R5 | 测多次未过 | 测挂 | 任一阶段测 **当日失败次数≥2** 或 **累计失败≥2** 且未过关（含队首测挂死） | 移队尾 / 插复习 / 重置重测（不自动跳过） |
| R6 | 长期失联 | 今日任务 | **连续 7 天** 今日任务完成率均为 0%，且期间有排计划 | 联系学生/家长 |
| R7 | 时长严重不足 | 今日时长 | 当前 ≥ **20:00** 且 已练 **&lt; 预算×25%** 且 今日任务 ≥1 | 与 R1 一并关注 |

### 5.1 可配置项（教师配置，首版可用默认值）

| 参数 | 默认 |
|------|------|
| 晚间检查时刻 | 20:00 |
| 下午零完成时刻 | 16:00 |
| 今日完成率红线 | 50% |
| 积压红线 | 3 |
| 测失败红线 | 2 |

## 7. 筛选 Chip 行为

| Chip | 筛选逻辑 |
|------|----------|
| **全部学生** | 默认；仅 `status=active` 学生 |
| **今日未完成** | 今日任务存在且 完成率 &lt;100% |
| **有积压** | 积压 ≥1 |
| **换题重学** | 换题 ≥1 |
| **测未过关** | 测挂 ≥1 |
| **需关注** | 行状态 = 🔴 |
| **无计划** | 行状态 = ⚪ |

- 多 Chip：**AND** 关系  
- 与搜索框：**AND**（学号/姓名模糊匹配）

### 7.1 默认排序

1. 状态优先级：🔴 → 🟡 → ⚪ → 🟢  
2. 同状态：积压降序 → 今日完成率升序 → 学号升序  

用户可点击列头排序：**今日任务完成率**、**积压**、**姓名**。

## 13. 双轨进度与进度表（线框补充）

与 [`task-system-overview.md`](task-system-overview.md) §8 一致：**计划轨**（任务 X/Y）与 **测试轨**（进度表 %/分/个）**不合并**；通过 `parent_module` 关联。

### 13.1 学生计划页 · 模块摘要（双列）

在学生计划页「有序清单」上方或右侧增加 **模块摘要表**（非班级总览）：

```text
┌─ 模块进度 ─────────────────────────────────────────────────────────────┐
│ 模块           │ 计划（任务）      │ 测试（进度表 · 只读）              │
├────────────────┼───────────────────┼──────────────────────────────────┤
│ 阅读同义替换   │ 学 5/8 过关 1/3   │ 78% / 目标 80%                   │
│ 听力1000词     │ 学 11/12 过关 5/6 │ 85% / 目标 80%  ✓                │
│ 口语 · 复合句  │ 学 3/17           │ —                                │
│ 口语 · P1      │ 学 8/24           │ —                                │
│ 口语（汇总）   │ —                 │ 6.0 / 目标 6.5                   │
└────────────────┴───────────────────┴──────────────────────────────────┘
```

- 左列 **计划**：仅该生清单内有的 `parent_module` / 口语子块  
- 右列 **测试**：来自现有 `test_records` + `MODULES`；口语汇总行只显示 **分**  
- **不**把 5/8 与 78% 合成一个进度条  

### 13.2 教师端 · 学习进度 Tab（测试轨 + 暂未安排）

在原有 **学习进度** 表（`tabProgress`）上增加 **计划状态** 列，与任务系统对齐：

```text
┌─ 学习进度（测试轨）────────────────────────────────────────────────────┐
│ 筛选模块 [全部▾]  …                                                    │
├────────────────────────────────────────────────────────────────────────┤
│ 学生 │ 模块       │ 计划状态   │ 目标 │ 最高分 │ 达标 │ 今日时长 │ …  │
├──────┼────────────┼────────────┼──────┼────────┼──────┼──────────┼────┤
│ 张三 │ 阅读同义   │ 已纳入计划 │ 80%  │ 78%    │ 否   │ 12分     │    │
│ 张三 │ 听力1000词 │ 已纳入计划 │ 80%  │ 85%    │ 是   │ 8分      │    │
│ 张三 │ 基础语法   │ 暂未安排   │ 85%  │ —      │ —    │ —        │    │  ← 灰显行
│ 张三 │ 口语练习   │ 已纳入计划 │ 6.5  │ 6.0    │ 否   │ 20分     │    │
└──────┴────────────┴────────────┴──────┴────────┴──────┴──────────┴────┘
```

**「暂未安排」行样式（已定）**

| 属性 | 值 |
|------|-----|
| 行背景 | `#f5f5f5` 或 `opacity: 0.55` |
| 文字色 | `#999` |
| 「计划状态」列 | 标签 **暂未安排**（灰色描边） |
| 最高分/达标/今日时长 | 仍可显示历史值（若有）；无数据为 `—` |
| 行点击 | **不**跳转模块学习页；Tooltip：「该科目尚未纳入任务计划，请在任务计划中拖入单元」 |
| 操作 | 可选链接「去排计划」→ 学生计划页 |

**「已纳入计划」**：该 `parent_module` 在学生清单中至少有 1 条 `study` 或 `test`；行正常色；测试列行为与现网一致。

### 13.3 学生端 · ③ 测试与能力（进度表区）

```text
┌─ 测试与能力（可折叠）──────────────────────────────────────────────────┐
│  阅读同义替换    测试 78% / 80%     [查看详情]                          │
│  听力1000词      测试 85% / 80%     [查看详情]                          │
│  基础语法        暂未安排            （整行灰显，无「去学习」）           │
│  口语练习        测试 6.0 / 6.5      [查看详情]                          │
└─────────────────────────────────────────────────────────────────────────┘
```

| 计划状态 | 样式 | 学生操作 |
|----------|------|----------|
| 已纳入计划 | 正常 | 可点「查看详情」看测试历史（**只读，禁进学习** D30）；**主学习路径仍走今日任务** |
| 暂未安排 | **灰显** + 文案 **暂未安排** | **禁止**从本表进入模块练习；避免与任务计划脱节 |

### 13.4 班级总览 vs 学习进度 Tab

| 页面 | 展示轨道 | 未纳入任务 |
|------|----------|------------|
| **班级总览** | 仅 **计划轨**（今日任务、计划进度简） | 计划列不显示该科 |
| **学习进度 Tab** | **测试轨** 为主 + **计划状态** 列 | 灰显 + 暂未安排 |
| **学生计划页** | **双列** 计划 + 测试 | 计划列无该行；测试列可灰显 |

### 13.6 学生 · 任务模式模块页（内容层线框）

与 [`task-system-overview.md`](task-system-overview.md) §7.5、[`task-system-spec.md`](task-system-spec.md) §10.1 一致。助教端不直接展示此页，但验收学生任务时需对照。

**通用结构**

```text
┌────────────────────────────────────────────────────────────┐
│ ← 返回今日任务                                              │
│ 今日任务 · {模块名} · {单元标题}                            │
│ 本单元：{scope_done}/{scope_total} {组|题|句}               │
├────────────────────────────────────────────────────────────┤
│  （仅 content_ref 范围；无全模块目录）                      │
└────────────────────────────────────────────────────────────┘
```

**与 ① 今日任务列表的关系**

| 位置 | 显示 | 禁止 |
|------|------|------|
| ① 列表组头 | 计划学习 **5/8** | 不出现本单元 3/10 |
| ① 单条条目 | 「学 · 单元 6」 | 不出现 78% |
| 模块页（任务模式） | **本单元 3/10 组** | 不出现 5/8、不出现 225 小组总量 |
| ③ 测试与能力 | 测试 **78%** | 不出现 3/10、5/8 |

**听力同义（必改 UI）**

```text
自由练首页：12 组 × 每组 10 题          ← 任务模式下不可出现

任务模式：
  今日任务 · 听力同义 · 单元 2（第 1 组 · 题 6–10）
  本单元：2/5 题
  [逐题练习，共 5 题]
```

**口语 P1**

```text
自由练：已完成 80 / 235 题             ← 任务模式下不可出现

任务模式：
  今日任务 · 口语 P1 · 单元 8
  本单元：7/10 题
```
