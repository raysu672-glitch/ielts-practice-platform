## 4. 科研摘要（上轮已检索，云端可据此继续，不必重搜一遍）

**能让学生学下去的，主要不是外在催促，而是：**

1. **自我决定理论 SDT**（Ryan & Deci；Howard 等 2021 元分析；Wang 等 2024 教育干预元分析）  
   - 胜任感 / 自主感 / 关系感  
   - **认同调节**与坚持相关强；**外在奖惩**难抬成绩与坚持，还伤幸福感  
   - 纯催 ≈ 外控，缺测 ≈ 胜任感无出口  

2. **形成性评价与反馈环**（Black & Wiliam 1998；OECD / Hattie 等）  
   - 目标 → 证据 → 可行动反馈 → **再练闭合**  
   - 有效反馈针对任务/过程，不是人格审判  
   - 注意：测提表现 ≠ 自动提高完课率（MOOC 证据），停学仍要分层召回  

3. **刻意练习**（Ericsson）  
   - 目标 + 适度难 + **即时反馈** + 针对错误再练  
   - 纯打勾时长 ≠ 提分练习  

4. **习惯 / 执行意图**（if-then、MCII/WOOP、习惯 App 研究）  
   - 重复后更自动，动机波动时仍能启动  
   - 「如果到点/打开 App，就先做今天第一项」优于空喊多学  

合成句：  
> 学下去 = 胜任感 + 清晰目标 + 可行动反馈 + 可重复启动习惯 + 适度关系支持；催只是辅。
